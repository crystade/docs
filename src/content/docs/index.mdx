## What is Crystade?

Crystade is a platform for teams that need reliable **cron jobs**, **health checks**, and **monitoring** in one place. Start with a personal workspace, then invite teammates when the project grows.

<CardGrid>
<Card title="Managed cron jobs" icon="rocket">
	Schedule recurring HTTP jobs and review execution history without running your own scheduler.
</Card>
<Card title="Health checks" icon="heart">
	Check whether important endpoints are responding as expected.
</Card>
<Card title="Monitoring" icon="chart">
	Track service availability and respond faster when something changes.
</Card>
<Card title="Team workspaces" icon="people">
	Keep resources, access, and billing organized by team.
</Card>
</CardGrid>
