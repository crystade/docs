## What is Crystade?

Crystade is a platform for teams that need **cron jobs**, **monitoring**, **incidents**, and **status pages** in one place. Start with a personal team, then invite teammates when the project grows.

<CardGrid>
<Card title="Cron jobs" icon="rocket">
	Schedule recurring HTTP requests and review every execution without running your own scheduler.
</Card>
<Card title="Monitoring" icon="chart">
	Probe HTTP, TCP, TLS, and Minecraft endpoints from multiple regions and evaluate the results with assertions.
</Card>
<Card title="Incidents and status pages" icon="warning">
	Track disruptions, publish updates, and give users a public page to check before they contact support.
</Card>
<Card title="Teams" icon="people">
	Keep resources, access, and billing organized by team.
</Card>
</CardGrid>
